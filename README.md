# VM3D-clone

The current Virtual Merri-bek 3D application is maintained in **`VM3D-clone.html`**.

## Project structure

- `VM3D-clone.html` — current consolidated application. Update this file for future changes.
- `archive/` — milestone and pre-cleanup snapshots retained for rollback.
- `index.html` — preserved as-is; it is a separate LiDAR Height Inspector page and was not changed during this cleanup.

## Versioning

Use GitHub commit history to track routine edits to `VM3D-clone.html`. Only copy a version into `archive/` when it represents a useful milestone or known-good fallback.

Live application: https://virtual-merri.github.io/VM3D-clone/VM3D-clone.html
